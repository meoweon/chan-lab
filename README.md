# 缠论实验室

Chan Lab — 可视化交互的缠论结构生成与验证工具

## 项目目标

把缠论构造成一个理想的、完整的、动态数学世界，通过可视化与交互，直观理解：

- 结构如何产生（包含处理 → 分型 → 笔 → 线段 → 中枢 → 买卖点）
- 彼此有什么关系（级别递归、背驰比较）
- 有哪些状态、如何转化（状态机追踪笔/中枢/买卖点的成立、待定、失效）
- 后续有哪些可能的发展路径（路径驱动 + 二叉完全分类）
- 如何用不同粒度观察（三种最小单元：单根 K 线 / 最小分型 / 最小笔）
- 理想结构如何被噪声污染（三层污染模型：路径噪声 / 形态噪声 / 结构污染）
- 如何接近真实行情（D 层真实噪声对齐 BTCUSDT 1h 风格化事实，同源 0 噪声基线对照）
- 自己构建走势或导入 CSV 真实数据分析

这不是交易软件，不是回测系统，而是理解缠论理论的"几何学圆模型"。

## 核心特性

### 结构链完整实现

包含处理 → 分型 → 笔 → 线段 → 中枢 → 背驰 → 买卖点，严格遵循无未来函数原则：信号记账于结构确认之 K 线，窗口不变性可验证。

### 状态机追踪

三台状态机（笔 / 中枢 / 买卖点）实时追踪结构的成立、待定、失效状态与转移路径，可视化状态网络。

### 路径驱动 + 二叉完全分类

给定路径即可复现完整结构演化，行动空间恒为「下一笔向上 / 向下」的二叉完全分类，支持同源基线对照。

### 三种最小单元

流程带支持三档粒度切换：单根 K 线 / 最小分型（默认）/ 最小笔，按步记录、只影响后续。

### 噪声验证

三层污染模型（路径噪声 / 形态噪声 / 结构污染）展示理想结构如何被逐步破坏；D 层真实噪声对齐 BTCUSDT 1h 风格化事实，同源 0 噪声基线严格 1:1 对照，双屏可视化差异。置换检验统计显著性，稳健度记分卡量化结构稳定性。

### 自建走势 + CSV 导入

理想世界内自建行情生成，也可导入 CSV 真实历史数据进行分析对照。

### 口径显式

流派分歧（新笔/老笔、线段破坏情形、终点取法）择一实现，以回归用例锁定。
