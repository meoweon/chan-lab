## 读数守则（如实）

1. p 值只在这**一份**数据、这**一组**信号上成立；多品种/多参数下要做多重比较校正，别对单次 p<0.05 过度兴奋。
2. 对照 B 的零假设是"无趋势、块内短相关"——真实趋势行情本就该和它不同；p 小说明信号与趋势结构挂钩，**不直接等于可交易**。
3. 末端凑不满持有期的信号已剔除（表中"剔除"列）；无次级别数据时为降级口径，与启用次级别确认的结果不可直接比。
4. 本报告由 stats-run.js 生成，不含任何对未来的断言；同参数同数据可逐位复现（种子 7）。
